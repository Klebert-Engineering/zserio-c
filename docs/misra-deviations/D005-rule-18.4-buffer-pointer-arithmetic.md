## Statement of the rule (paraphrased)

Rule 18.4 advises that the `+`, `-`, `+=`, and `-=` operators should
not be applied to expressions of pointer type.

## Where it is deviated

Call sites computing a byte offset into a borrowed `uint8_t *`
buffer:

- `runtime/src/bytes.c:42` — `bs->buffer + (bs->bit_index / 8U)`
  inside `zserio_read_bytes_view`
- `runtime/src/extern.c:50` — `bs->buffer + base_byte` inside
  `zserio_read_extern_view`
- `runtime/src/string.c:69` — `bs->buffer + (bs->bit_index / 8U)`
  inside `zserio_read_string_view`
- `runtime/src/allocator.c:98` — `a->buf + aligned` inside the
  bump-arena `alloc` callback (the byte offset is the
  alignment-adjusted `used` cursor inside the caller-owned arena
  buffer).

All three sites compute a pointer to the start of a payload that
follows a varsize length prefix in the bitstream's borrowed byte
buffer. The pointer arithmetic is the natural way to express
"address of byte N in the buffer".

## Justification

The runtime's bitstream is an in-memory byte buffer with a tracked
bit position; the byte-offset pointer arithmetic is the most
direct and least error-prone way to compute the address of a
specific byte. The only alternative MISRA permits — array
subscripting `&bs->buffer[bit_index / 8U]` — is semantically
identical and is subject to the same out-of-bounds risks; cppcheck
itself treats the two forms equivalently.

The bound check in each call site (`(size_t)length > remaining_bits / 8U`
or its analogue) ensures that the computed pointer always points
within the allocated buffer plus one (the C99-allowed
one-past-the-end position).

## Mitigation

- Each pointer-arithmetic site is preceded by an explicit bounds
  check against `bs->buffer_bit_size` that subtracts the consumed
  bit count from the buffer's bit capacity (REQ-FS-005 spirit).
- The resulting pointer is always written into a `zserio_*_view_t`
  struct that the caller is documented to use only while the
  source buffer is alive.
- Round-trip tests in `tests/runtime/test_string.c`,
  `test_bytes.c`, and `test_extern.c` cover both byte-aligned and
  bit-misaligned source positions, exercising the pointer
  arithmetic against a known buffer layout.
