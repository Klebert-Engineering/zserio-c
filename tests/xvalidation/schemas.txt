# DEFERRED: packed_arrays_mapping — 30-field packed kitchen sink.
# Cpp reader hits EOF on our output for every seed, so one or more
# of the packed array encoders produces fewer bits than cpp
# expects. Localising via cpp oracle hasn't been done yet.
#   array_types/zs/array_types/packed_arrays_mapping.zs

# DEFERRED: packages/zs/index.zs — top-level package literally named
# `index` collides with libc's `index()` declared via `<strings.h>`.
# Upstream cpp uses `-setTopLevelPackage` to remap. Our cpp_driver
# doesn't apply that and the cpp side fails with `namespace index
# redeclared as different kind of entity`. Pure cpp toolchain issue,
# nothing for the C generator to fix.
#   packages/zs/index.zs

# DEFERRED: cross-compound offset sources. Our wrapOffsetSource
# only handles atomic SIBLING fields as offset source. When the
# source is dotted (`x.offset:` where x is a parameter compound, a
# child struct, a choice arm, or a union arm), we leave the source
# field at 0 and cpp reports `Wrong offset for field ...`.
#   offsets/zs/offsets/parameter_offset.zs   — source in parameter compound
#   offsets/zs/offsets/offset_in_choice.zs   — source in sibling choice arm
#   offsets/zs/offsets/offset_in_union.zs    — source in sibling union arm

# DEFERRED: optional_recursion — an optional self-referential struct
# member is emitted by value (`optional_members_optional_recursion_block_t
# next_data;`) which is an incomplete type. Needs heap indirection
# in the generator for any optional/conditional self-referential field.
#   optional_members/zs/optional_members/optional_recursion.zs
